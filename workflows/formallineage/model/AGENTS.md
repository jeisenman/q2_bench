# Shared formal model

Pure Go contracts shared across runtimes. Existing `q2-formal-method/v1` JSON
and the Spark profile remain byte-compatible. Syntax discovery uses separate
catalog records with explicit runtime/source identities and unresolved status.
Catalog operations are source observations, not executable steps or proofs of
call binding. Never evaluate a Pandas or .NET method using Spark semantics.
No network, Git, parser or SDK dependencies belong in this package.
