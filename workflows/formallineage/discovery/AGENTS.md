# Common source discovery

This package maps Python, C# and TypeScript syntax into the same source catalog
and common program contract. Operator names are lexical candidates. Preserve
source spans, imports and call spellings; do not claim resolved call/dataflow
edges. All discovered programs remain unknown with no executable steps until
their runtime lowering and bindings are implemented. Pandas and C# never use
the Spark evaluator by default. Preserve module-level notebook operations and
magic-cell gaps. Bound tree depth, declarations, operations and snippet bytes.
