# Suggest a definition

Use lineage tools to find the exact dataset and column identity, current
sources, and snapshot. Get business meaning from the SME or attributable
evidence. Never invent approved meaning.

Use the definitions schema. Pin the current node and source digests. Show the
draft and its pins to the SME. Use `draft_definition` for a private draft. Use
`submit_definition_pr` when the SME asks to submit.

Report a successful PR only if the tool returns one. Submission makes the text
visible to repository readers. It does not approve or merge the PR.
